# DocuMind web

React + TypeScript + Vite front-end for DocuMind.

```bash
npm install
npm run dev     # http://localhost:5173 (API calls are proxied to http://localhost:5080)
npm run build   # type-check and build to dist/
npm run lint    # oxlint
```

Start the API first. See the [main README](../README.md) for the full setup.
